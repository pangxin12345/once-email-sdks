# Once Email Skill prompts

Created by https://once-email.com

Use only for a local, test, or staging application you own or are explicitly authorized to test. Never paste an API key, inbox address, OTP, link, message, attachment, or cleanup journal into a prompt.

## Add one Playwright OTP test

```text
Use the Once Email test-email-flows Skill to add one email OTP test to this authorized staging project. Reuse the existing test framework. Run doctor and plan first, keep sensitive values in-process, disable screenshots/video/traces, validate only redacted output, and require cleanup=cleaned. Never expose an address, OTP, link, message, API key, or cleanup journal.
```

## Diagnose a failure

```text
Diagnose this authorized project's redacted email-flow failure with the Once Email Skill. Preserve timeout, ambiguity, API, assertion, and cleanup meanings. Do not open or quote sensitive files; report only validated non-sensitive results.
```
