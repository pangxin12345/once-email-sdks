# Security policy

Do not open a public issue containing an email address, message, OTP, link, attachment, API key, token, internal resource identifier, full URL, report, or cleanup journal.

Until the official GitHub security channel is live, use the private support form at `https://once-email.com/contact` and include only a redacted reproduction, affected version, operating system, stable error code, and cleanup result. Never attach the original report or journal.

Supported public versions will be listed here only after publication. Private candidates may change without compatibility guarantees.
