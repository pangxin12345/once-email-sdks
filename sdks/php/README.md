# once-email/sdk

Receive-only temporary inbox API for authorized email-flow testing. Public access is not open.


## Installation & Usage

### Requirements

PHP 7.4 and later.
Should also work with PHP 8.0.

### Composer

To install the bindings via [Composer](https://getcomposer.org/), add the following to `composer.json`:

```json
{
  "repositories": [
    {
      "type": "vcs",
      "url": "https://github.com/pangxin12345/once-email-sdks/sdks/go.git"
    }
  ],
  "require": {
    "pangxin12345/once-email-sdks/sdks/go": "*@dev"
  }
}
```

Then run `composer install`
